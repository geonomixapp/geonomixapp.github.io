Clés des notifications

Cette page fabrique les deux clés des notifications de Geonomix sur ton appareil. Rien n'est envoyé nulle part. Fais-le une seule fois.

1. Clé publique

Celle-ci, tu peux l'envoyer à Claude : elle est faite pour être publique.

2. Clé privée

Celle-ci est secrète : ne l'envoie à personne, pas même à Claude. Colle-la seulement dans Supabase (Edge Functions → Secrets), sous le nom VAPID_PRIVATE_KEY. Colle aussi la clé publique sous le nom VAPID_PUBLIC_KEY.

Si tu recharges cette page, de nouvelles clés sont fabriquées : garde bien ces deux-là jusqu'à les avoir collées.
